Playback languages

NextFlix keeps the provider’s main/default audio track. Choose a preferred subtitle language; subtitles stay off if it is unavailable.

TV guide and XMLTV

Use the provider’s guide by default, or enter an XMLTV URL. Guide data is cached on this TV and refreshed every 12 hours when NextFlix is running.

Manual channel mapping

Select a live channel and an XMLTV channel to map them.

Backup and restore

Export your NextFlix settings in an encrypted file. The file includes saved provider credentials, profiles, favorites, category visibility, guide mappings, and watch history. Keep the password safe; it cannot be recovered.

Backups exclude cached artwork and rebuildable catalog/guide data.

Diagnostics and cache

Select Refresh diagnostics to inspect this app’s local capabilities and cache.

Movie information and subtitles

This product uses the TMDB API but is not endorsed or certified by TMDB. The Movie Database supplies optional metadata.
