Movie information and subtitles

These optional API keys are saved in this TV’s browser storage, unencrypted. Treat them like passwords. NextFlix sends them directly to their respective services; they are not sent to NextFlix servers. TMDB can add movie and series descriptions, artwork, genres, and cast; OpenSubtitles.com can find external subtitles when the stream has none.

  1. TMDB API settings: create a TMDB account, request an API key, and copy the API Key (v3 auth). The API Read Access Token is also accepted.
  2. OpenSubtitles API consumers: sign in, register an application, and copy its API key. A website account password is not an API key.
  3. Enter each value below and choose Save API keys. Leave either field blank if you do not want that service.
