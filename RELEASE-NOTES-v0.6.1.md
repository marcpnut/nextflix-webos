# NextFlix v0.6.1

## Included

- Optional TMDB metadata enrichment for confidently matched movie and series details.
- Optional OpenSubtitles.com search and external subtitle playback for VOD when the stream has no selectable subtitles.
- API keys are entered by the user and stored locally on the TV; neither service is required to use NextFlix.
- The Homebrew catalog now points to the current installable package.

## Notes

- External subtitle availability depends on the provider stream, title matching, API access, and webOS media support.
- Test the update on the target LG TV before relying on new metadata or subtitle behavior.
