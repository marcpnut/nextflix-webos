# NextFlix v0.6.4

- Replaced scroll cue glyphs with CSS-drawn directional arrows so their appearance does not depend on the TV's installed symbol fonts.
- Subtitle controls are reachable using predictable left/right remote navigation.
- Player title and control overlays hide after five seconds while playback is running and return on remote input.
- Leaving the subtitle menu closes it and resumes the player control hide timer.
- HTML/WebVTT subtitle cues are positioned slightly higher on screen.

Native webOS subtitle rendering may not expose cue position control. Verify scrolling arrows, menu navigation, and subtitle placement on the target TV.
